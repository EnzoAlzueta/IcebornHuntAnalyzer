# Iceborn Hunt Analyzer

[![Ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/imkyril)

A planned Windows desktop viewer for the local hunt archive written by Iceborn Damage Meter.

**Project status — planning.** The first milestone is a read-only decoder for the meter’s IDMHARC1 archive. Its tests will cover complete records, damaged input and a final record still being written.

## Planned features

- Open a local archive and browse its complete hunt records.
- Inspect an individual hunt and filter by date, quest or weapon.

## Requirements and scope

The proposed input is `nativePC/plugins/iceborne_damage_meter_hunts.bin` from Iceborn Damage Meter 0.6.12 or later.

## Development

See the [roadmap](ROADMAP.md) for the first milestone and its acceptance criteria. For the related mod, see [Iceborn Damage Meter](https://github.com/EnzoAlzueta/IcebornDamageMeter).

## Availability

There is no installable build or gameplay validation yet.
