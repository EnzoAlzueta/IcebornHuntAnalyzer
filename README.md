# IcebornHuntAnalyzer

Planned desktop analyzer for archived Iceborn Damage Meter hunts.

Planning repository for a read-only desktop viewer of archives produced by [IcebornDamageMeter](https://github.com/EnzoAlzueta/IcebornDamageMeter). The first milestone is a bounded decoder and a basic hunt browser.

## Development

The application is in planning. See the [roadmap](ROADMAP.md).
